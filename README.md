# 🔍 My Database Web App

Μια απλή και δοκιμαστική εφαρμογή που χρησιμοποιεί βάση δεδομένων και web τεχνολογίες όπως **Python**, **HTML**, **CSS** και **JavaScript**. Δημιουργήθηκε για εξάσκηση και πειραματισμό με full-stack ανάπτυξη.

## 💡 Χαρακτηριστικά

- Web περιβάλλον χρήστη (UI) με HTML/CSS
- Δυναμικές λειτουργίες με JavaScript
- Διαχείριση δεδομένων μέσω Python 
- CRUD λειτουργίες (Create, Read, Update, Delete)
- Σύνδεση με βάση δεδομένων (SQLite)

## 🛠️ Τεχνολογίες

- **Frontend**: HTML, CSS, JavaScript  
- **Backend**: Python (Flask)
- **Database**: SQLite
